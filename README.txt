وكالة PRO - نسخة معاينة مجانية
افتح index.html في متصفح الكمبيوتر للمعاينة. للحصول على تثبيت PWA وعمل Service Worker، ارفع الملفات إلى استضافة HTTPS ثابتة أو شغل خادماً محلياً (python -m http.server 8000) ثم افتح http://localhost:8000.
البيانات تجريبية ومحفوظة محلياً في localStorage للمتصفح. لا توجد مزامنة بين الأجهزة أو تسجيل دخول أو قاعدة بيانات خادمية. استعمل زر تصدير نسخة احتياطية لحفظ بياناتك.
